# CPCS-371 Computer Networks — Unofficial Interactive Visual Study Companion

An offline-capable, interactive single-page study textbook for **CPCS-371 Computer Networks (I)** at King Abdulaziz University (KAU), based on *Computer Networking: A Top-Down Approach* (6th/8th Ed.) by Kurose & Ross.

> **💡 Disclaimer & Educational Fair-Use Notice:**  
> This project is an independent, **unofficial student study companion** created strictly for peer learning, review, and exam revision. It is **not** an official publication of, nor affiliated with or endorsed by, King Abdulaziz University (KAU) or Pearson Education. All curriculum topics, problem sets, and theoretical references belong to their respective authors and publishers.

## Features
- **All 9 Chapters** fully expanded with deep textbook rigor.
- **43 Inline SVG Architecture Diagrams & Timelines** (protocol timelines, TCP/UDP headers, rdt 3.0 scenarios, and more).
- **Interactive Visual Simulators**:
  - Live Packet Journey Simulator (§1.1)
  - Nodal Delay Calculator (§1.4)
  - 16-bit Internet Checksum Calculator (§3.3)
  - CIDR Subnet Calculator (§4.3)
  - CDMA Chipping Code Decoder (§7.2)
  - RSA Key Generator & Cipher (§8.2)
  - Stateless Packet Filter Simulator (§8.9)
  - Token Bucket Leaky Bucket Simulator (§9.4)
- **Midterm Exam Preparation (Chapters 1–3)**:
  - All 24 Practice Problems (**P1–P24**) with full step-by-step collapsible solutions.
  - 55-item checklist covering all 42 official *"I CAN ..."* objectives.
- **50-Question Timed Mock Exam** with automated scoring and review explanations.
- **100% Self-Contained**: Zero external CDNs, zero image dependencies, runs entirely in the browser offline.
